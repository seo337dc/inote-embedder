# A2 결과 — 임베딩 서비스 첫 실행 (2026-10-12)

환경: Intel Mac(x86_64) · macOS 15 · Docker Desktop 4.94.0 · 컨테이너 배정 CPU 12 / 메모리 상한 5GB · **GPU 없음(CPU 추론)**

## 설치·크기
| 항목 | 값 |
|---|---|
| 도커 이미지 | 약 **427MB** (파이썬 3.12-slim + CPU 전용 torch 2.14.1 + sentence-transformers 6.1.0 …) |
| 모델 | `nlpai-lab/KURE-v1`, 가중치 391개 텐서, 차원 **1024** — 첫 시작 때 Hugging Face에서 내려받아 볼륨(`/models`)에 저장 |
| 첫 시작(모델 내려받기+로드) | 약 **2분** |
| 재시작(볼륨에 모델 있음) | 약 **15초** |
| 메모리 | 추론 직후 `docker stats` **약 927MiB** (상한 5GiB) — 예상(2~3GB)보다 작다. 긴 입력·동시 요청에서의 최대치는 아직 안 쟀다 |

## 지연 (`scripts/bench.py`, 각 5회)
| 입력 | 처음 | 중앙값 | 최소~최대 |
|---|---|---|---|
| 짧은 문장 1개 | 600 ms | **360 ms** | 217~600 ms |
| 짧은 문장 8개 (배치) | 911 ms | **911 ms** | 809~1019 ms |
| 긴 글 1개 (1,152자) | 2,591 ms | **2,569 ms** | 2,366~2,998 ms |

해석: 짧은 문장은 0.2~0.6초, **글 한 편(약 1천 자)은 약 2.5초**. 글 저장 때 뒤에서 계산(A5)하기엔 충분하고, 글을 쓰는 중 실시간 호출(C)은 입력 길이 상한·디바운스가 필요하다. 배치 8개가 1개의 약 2.5배라 배치 이득은 크지 않다(CPU 한계).

## 한국어 유사도 눈 확인 (정규화 벡터의 내적 = 코사인)
| 구분 | 점수 | 문장 쌍 |
|---|---|---|
| 비슷함 | 0.953 | 오늘 점심으로 김치찌개를 먹었다 ↔ 점심 메뉴로 김치찌개를 먹었어요 |
| 비슷함 | 0.810 | 도커 컨테이너로 서버를 실행했다 ↔ docker로 서버를 띄웠다 |
| 비슷함 | 0.685 | 리액트에서 상태를 관리하는 방법 ↔ React 상태 관리 라이브러리 비교 |
| 비슷함 | 0.902 | 이직 준비를 위해 이력서를 고쳤다 ↔ 이력서를 수정하며 이직을 준비하고 있다 |
| 무관함 | 0.302 | 점심 김치찌개 ↔ 임베딩 모델은 문장을 벡터로 바꾼다 |
| 무관함 | 0.373 | 도커 컨테이너로 서버를 실행했다 ↔ 주말에 가족과 제주도로 여행을 갔다 |
| 무관함 | 0.302 | 리액트 상태 관리 ↔ 삼겹살은 불판에 바싹 구워야 맛있다 |
| 무관함 | **0.502** | 이직 준비로 이력서를 고쳤다 ↔ 비가 와서 우산을 챙겨 출근했다 |

- 비슷한 쌍 평균 0.838 / 무관한 쌍 평균 0.370 / 차이 0.468. 이 작은 예에서는 **가장 낮은 비슷함(0.685) > 가장 높은 무관함(0.502)** 로 구분된다.
- **영어/한국어 혼용(React ↔ 리액트)은 0.685로 가장 낮다** — 글에 영어 용어가 많은 이 블로그에서는 기준값(τ)을 정할 때 이 경우를 따로 봐야 한다.
- **무관한 쌍도 0.3~0.5로 0에 가깝지 않다.** 이 모델의 점수는 대체로 높은 쪽에 몰려 있어서, "비슷하다"의 기준값은 **0.5 근처가 아니라 평가 세트로 더 높게** 잡아야 한다(PLAN 7절). 표본 8쌍이라 숫자를 일반화하지 않는다.
